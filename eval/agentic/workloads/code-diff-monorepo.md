# Workload: Package Changes in a Monorepo

Investigate raw source changes between public npm `react` versions `19.0.0`
and `19.1.0`. Start with a bounded overview, then inspect changes under
`packages/react/` and summarize what the evidence supports about that package.

Explain the scope of each result, whether sibling packages can appear, and
whether a bounded overview without React source paths proves React unchanged.
Report any file or content limits. Do not treat raw source evidence as proof
that an upgrade is compatible or safe.
