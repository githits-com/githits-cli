# Workload: Documentation-Site Resolution And Search

An internal research note names its source only as `Express docs`; do not assume
a hostname. Identify the exact public standalone documentation site it most
likely means. Preserve ambiguity if the available evidence warrants it. Then
use that site's own documentation to explain how route parameters are exposed
to route handlers, including source URLs or page IDs in the answer.

Distinguish identity inference from documentation evidence.
