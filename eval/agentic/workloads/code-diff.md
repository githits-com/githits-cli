# Workload: Exact Express Source Changes

Review the exact source changes between public npm `express` versions `5.2.0`
and `5.2.1`. Identify which source files changed, with particular attention to
files under `lib`, and provide a bounded code-level summary of the changes.

Distinguish exact raw source evidence from compatibility or upgrade-safety
claims. Raw source changes alone must not be presented as proof of compatibility
or safety.
