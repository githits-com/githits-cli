- **Compact code-symbol reads** - Read package and repository symbols with `target#symbol` in the CLI and MCP tool, with an optional exact path. The backend's unified result determines code or documentation presentation, preserving HTTP(S) documentation fragments and emitted repository page IDs without client-side source guesses. Hosted MCP support requires a package release and adoption by the remote server.
